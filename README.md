# Password Generator

A simple command-line Python script that generates random passwords with a custom length and optional special characters.

## Features
- Choose password length (minimum 4 characters)
- Option to include special characters
- Basic input validation

## How to run
```bash
python generator.py
```
Only uses built-in Python modules (`random`, `string`).
